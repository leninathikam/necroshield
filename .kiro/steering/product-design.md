# Product design

Use a restrained charcoal, violet, and amber command center. Let the real attack graph, execution timeline, policy reason, and paired outcomes establish the visual hierarchy.

Provide keyboard focus, readable contrast, semantic buttons, labels, responsive layouts, reduced-motion handling, and text equivalents for graph outcomes. Never rely on color alone to identify allow/deny.

Show true empty, loading, unavailable-backend, failed-run, and completed states. Metrics come only from the selected run or benchmark. Use null/unavailable labels where nothing was measured.

Animation may indicate pending execution. Do not animate prerecorded events as though a live model is executing. Show synthetic fixture mode prominently and explain replay semantics next to comparison results.

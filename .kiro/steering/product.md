# Product intent

NecroShield is an authorized synthetic security arena for agent tool workflows. Its central demonstration is a paired run: the same bounded tool intents execute with and without a deterministic authorization gateway, while legitimate task completion remains visible.

Every screen must distinguish deterministic fixture execution from a stochastic model evaluation. Never describe fixture results as real-model robustness. Never invent run results, latency, cost, Kiro contributions, or prize eligibility.

Optimize for an investigator answering: what untrusted input arrived, what action was proposed, why did policy allow or deny it, what effect actually occurred, and did the task finish?

The Frankenstein entry combines policy-as-code, agent execution, MCP, causal replay, and forensic evidence. Eligibility requires genuine Kiro work and separate submission artifacts; project configuration alone is insufficient.
